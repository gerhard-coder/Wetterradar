# Wetterradar für Motorradfahrer

Private Web-App (PWA) für Android. Installation: Seite in Chrome öffnen → Menü ⋮ → „App installieren“.

- Städtesuche mit Vorschlägen (Open-Meteo Geocoding)
- Favoriten: speichern ☆, sortieren (Griff ≡ ziehen oder ▲▼), löschen ✕ mit Rückgängig
- 16 Tage: Tag 1–7 normal, ab Tag 8 als „Tendenz“ mit Spannweite aus 82 Ensemble-Läufen (ECMWF + GFS)
- Regenradar: DWD RV-Produkt, 90 min gemessen + 2 h Vorhersage, animiert über OpenStreetMap
- Motorrad-Ampel pro Stunde und Tag, Fahrer-Illustration je Wetterlage

Daten: Open-Meteo (CC BY 4.0), Deutscher Wetterdienst, © OpenStreetMap-Mitwirkende.
